# Personal Portfolio — Flutter Web

A responsive, minimalist software engineering portfolio built with Flutter and Dart.

The design direction combines a monochrome visual identity with subtle manga-inspired artwork, clean typography, and interactive project demonstrations.

## Goals

- Showcase software engineering projects and technical skills.
- Present project case studies, architecture, and engineering decisions.
- Provide an interactive, browser-based JARVIS demonstration.
- Demonstrate responsive design across desktop, tablet, and mobile browsers.
- Publish the portfolio using GitHub Pages.

## Technology Stack

- Flutter Web
- Dart
- Visual Studio Code
- Git and GitHub
- GitHub Pages (planned deployment)

## Design Direction

- Black-and-white visual theme
- Minimalist layouts and typography
- Manga-inspired illustrations and panel details
- Responsive navigation and reusable UI components

## Getting Started

Install the Flutter SDK and Git, then open this repository in Visual Studio Code.

Run the following commands from the project root:

```bash
flutter pub get
flutter run -d chrome
```

To check the project for static analysis issues:

```bash
flutter analyze
```
